# 문제 1번
## Arduino IDE(통합 개발 환경)을 설치하라.

아두이노 IDE 공식 웹 사이트: 
https://www.arduino.cc/en/software/

운영체제에 맞게 다운로드 한다.

## Arduino IDE를 다운로드하고 설치하는 구체적인 방법을 설명하라.

https://www.arduino.cc/en/software/

Windows: 아두이노 공식 홈페이지에서 최신 설치 파일(.exe)을 다운로드한 후, 파일을 더블 클릭하여 설치 마법사의 안내에 따라 설치. 설치 완료 후 IDE를 실행

macOS: 공식 홈페이지에서 .dmg 파일을 다운로드하고, 파일을 열어 Arduino IDE 아이콘을 Applications 폴더로 드래그하여 설치

Linux: AppImage 파일을 다운로드한 후, 파일의 속성에서 실행 권한을 부여하고 더블 클릭하여 실행합니다. 필요 시 터미널에서 sudo apt-get -y install libfuse2 명령어로 의존성을 설치해야 할 수도 있음.

<br>


## 아두이노 보드를 Arduino IDE에 연결하는 과정을 설명하라.

1. 아두이노 IDE을 킨 채로 USB 케이블로 아두이노 보드를 컴퓨터에 연결함.
   
2. 도구 -> 보드 를 클릭해서 사용하는 보드를 선택함.
 
3. 도구 -> 포트에서 사용하는 포트를 선택함.

   <br>
   
## 새로운 아두이노 프로젝트를 시작하는 방법을 기술하라.

파일 -> 새로 만들기 : 새로운 스케치 생성됨.

<br>

## 아두이노 보드에 스케치(프로그램)를 업로드하는 과정을 설명해보라.

코드 작성 후 상단에 업로드 버튼을 클릭한다.

업로드가 완료 되면 보드에서 프로그램이 실행된다. 오류가 발생하면 터미널에 메세지가 뜬다.

<br><br>

## 라이브러리(Library)를 아두이노 프로젝트에 추가하는 방법은 무엇인가?

Library Manager 사용 : 왼쪽 세번째 아이콘을 선택하여 원하는 라이브러리를 검색 후 Install 버튼을 클릭

<br>

## 아두이노 보드의 포트를 선택하는 이유를 설명해 보라.

특정 포트를 선택해야 IDE과 연결되어 프로그램 통신, 업로딩이 가능해지기 때문이다.
포트 선택이 잘못되면 업로드 오류나, 다른 장치로 신호가 전송됨.

<br><br>


## 시리얼 모니터를 사용하여 아두이노 보드에서 나오는 데이터를 모니터링하는 방법을 설명하시오

스케치에 Serial.begin(9600); 등으로 시리얼 통신을 초기화

코드 업로드 후, IDE 우측 상단의 시리얼 모니터 버튼을 클릭하면 하단에 시리얼 모니터 창이 열림.

보드에서 송신한 데이터(예: Serial.println("???");)가 실시간으로 표시됨.

<br><br>

## Arduino IDE에서 코드를 저장하고 관리하는 방법은?

저장: 파일 -> 저장 또는 Ctrl+S 단축키로 현재 스케치를 저장

프로젝트 관리: 각 스케치는 별도의 폴더에 저장되며, .ino 파일과 관련 파일이 함께 관리

<br><br>

## Arduino IDE의 기본 설정을 변경하는 방법은?

설정 : 파일 -> 설정 / IDE -> 설정
고급 설정: Command Palette(Ctrl+Shift+P 또는 F1) 에서 Preferense
