# 문제 2

## 사전 지식 

LED 다리 구분
- 긴 다리(Anode, +): 전기(신호)가 들어오는 쪽
- 짧은 다리(Cathode, -): 전기가 빠져나가는 쪽
<br>

아두이노 핀
- 디지털 핀: 제어 신호를 보냄
<br>

GND(그라운드): 전기가 빠져나가는 곳

<br>
<br>

## 1. GPIO를 사용하여 LED 제어하기

#### 회로 구성 방법
아두이노 우노 보드와 브레드보드를 사용합니다.

LED의 긴 다리(+)를 브레드보드에 꽂고, 저항(220Ω~330Ω)을 LED의 짧은 다리(-)와 연결합니다.
아두이노의 8번 디지털 핀에서 브레드보드의 LED 긴 다리(+)로 점퍼선을 연결합니다.
저항의 다른 쪽을 브레드보드에서 점퍼선으로 아두이노 GND에 연결합니다.

<img width="532" alt="image" src="https://github.com/user-attachments/assets/ddf65e29-00e4-471a-bd9a-85d458276d02" />


``` 
void setup() // 1.
{
  pinMode(8, OUTPUT);  // 2. 8번 핀을 출력모드로 설정
}

void loop() // 3.
{
  digitalWrite(8, HIGH); // 4. 해당 핀을 5V를 출력해서 LED를 킴(8번)
  delay(1000); // 5. 1000ms=1초
  digitalWrite(8, LOW); // 6. LOW: 전압이 0V로 설정됨.
  delay(1000);
}
``` 

## 2. S.O.S 모스부호 신호 알고리즘 설계

S.O.S는 모스부호로 ... --- ... 이다.
S: 점 3개 (짧게 3번 깜빡임)
O: 선 3개 (길게 3번 깜빡임)
점(Short): 200ms 켬, 200ms 끔
선(Long): 600ms 켬, 200ms 끔
문자 간(각 S, O 사이): 400ms
반복 간격: 1초

``` 
int ledPin = 8; // LED 연결 핀

void setup() {
  pinMode(ledPin, OUTPUT); // 8번 핀을 출력으로 설정
}

// 아래 과정을 무한반복함.
void loop() {
  // S: 점 3번
  for(int i=0; i<3; i++) {
    flash(200);
  }
  delay(400); // 문자 간 간격

  // O: 선 3번
  for(int i=0; i<3; i++) {
    flash(600);
  }
  delay(400); // 문자 간 간격

  // S: 점 3번
  for(int i=0; i<3; i++) {
    flash(200);
  }
  delay(1000); // S.O.S 반복 전 대기
}

// LED 점멸 함수
void flash(int duration) {
  digitalWrite(ledPin, HIGH); // LED 켜기
  delay(duration); // 딜레이 시간 유지 
  digitalWrite(ledPin, LOW);  // LED 끄기
  delay(200);                 // 점/선 사이 공백
}
``` 


## 3. 여러 LED와 전원 계산

LED 1개: 20mA 전류 필요

LED 여러 개: LED 수 × 20mA = 총 전류

예시: 10개 LED → 200mA 필요

5V 어댑터 선택: 총 전류보다 여유 있는 어댑터 사용(예: 0.5A 이상)

저항 선택: (5V - LED 전압)/0.02A ≈ 150~220Ω 사용
